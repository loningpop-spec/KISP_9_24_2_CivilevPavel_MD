# Конспект Expo
**Expo** — это фреймворк React Native, упрощающий разработку приложений для Android и iOS. Фреймворк предоставляет маршрутизацию на основе файлов, стандартную библиотеку нативных модулей и многое другое.
### Системные требования
- Node.js (LTS )
- Поддерживаются macOS, Windows (Powershell и WSL 2 ) и Linux.
### Создание нового проекта
Для создания нового проекта выполните следующую команду:  
`npx create-expo-app@latest`
### Начнём с примера.
Вместо проекта по умолчанию вы можете начать с одного из примеров Expo. Это небольшие приложения, каждое из которых демонстрирует определенную функцию или интеграцию.

Чтобы просмотреть весь список и выбрать нужный пункт в интерактивном режиме введите следующую команду:  
`npx create-expo-app@latest --example`  

Чтобы создать известный пример напрямую, передайте его имя:  
`npx create-expo-app@latest --example with-widgets`

### Настройте агента ИИ.
Новый проект включает файлы контекста проекта, которые считывают агенты ИИ: AGENTS.md , CLAUDE.md и .claude/settings.json . Claude Code и Codex также имеют официальный плагин Expo. С помощью одной команды вы можете установить Expo Skills и зарегистрировать сервер Expo Model Context Protocol (MCP):  
`claude plugin install expo@claude-plugins-official`

# Инструменты для разработки
При создании нового проекта в Expo знание следующих важных инструментов и веб-сайтов может помочь вам в процессе разработки приложения

### Expo CLI
**Expo CLI** — это инструмент разработки, который устанавливается автоматически вместе с expoпакетом при создании нового проекта. Вы можете использовать его, задействовав `npx` (сервис запуска пакетов Node.js).  
Он разработан, чтобы помочь вам быстрее продвигаться на этапе разработки приложения. Например, ваше первое взаимодействие с Expo CLI — это запуск сервера разработки с помощью команды: `npx expo start`  
Ниже приведён список распространённых команд, которые вы будете использовать с Expo CLI при разработке своего приложения:

|Командование|Описание|
|-|-
|`npx expo start`|Запускает сервер разработки (независимо от того, используете ли вы сборку для разработки или Expo Go).|
|`npx expo prebuild`|Создает собственные каталоги Android и iOS с помощью Prebuild.|
|`npx expo run:android`|Компилирует локальное нативное Android-приложение.|
|`npx expo run:ios`|Компилирует локальное нативное iOS-приложение.|
|`npx expo install package-name`|Используется для установки новой библиотеки или проверки и обновления определенных библиотек в вашем проекте путем добавления `--fix` соответствующей опции к этой команде.|
|`npx expo lint`|Настройка и конфигурирование ESLint. Если ESLint уже настроен, эта команда проверит файлы вашего проекта.|

Вкратце, Expo CLI позволяет разрабатывать, компилировать, запускать приложения и многое другое.

### EAS CLI
EAS CLI используется для входа в вашу учетную запись Expo и компиляции вашего приложения с помощью различных сервисов EAS, таких как Build, Update или Submit. Вы также можете использовать этот инструмент для:

- Опубликуйте свое приложение в магазинах приложений.
- Создайте сборку для разработки, предварительного просмотра или продакшена вашего приложения.
- Создавайте обновления по беспроводной сети (OTA).
- Управляйте учетными данными приложения.
- Создайте специальный профиль подготовки для устройства iOS.  

Для использования EAS CLI необходимо установить его глобально на локальном компьютере, выполнив команду:  
`npm install --global eas-cli`  
Вы можете использовать eas --helpкоманду `npm install` в окне терминала, чтобы узнать больше о доступных командах.

### Экспо Доктор
**Expo Doctor**  — это инструмент командной строки, используемый для диагностики проблем в вашем проекте Expo. Чтобы использовать его, выполните следующую команду в корневом каталоге вашего проекта:  
`npx expo-doctor`

Если Expo Doctor обнаружит проблему, он предоставит описание проблемы, а также рекомендации по ее устранению или информацию о том, где найти помощь.  
По умолчанию Expo Doctor проверяет пакеты вашего проекта на соответствие каталогу React Native и проверяет, правильно ли синхронизированы свойства конфигурации приложения, если существуют каталоги нативных приложений.

### Орбита
**Orbit** — это приложение для macOS, Windows и Linux, которое позволяет:
- Устанавливайте и запускайте сборки из EAS на физических устройствах и эмуляторах.
- Устанавливайте и запускайте обновления через EAS на эмуляторах Android или симуляторах iOS.
- Запускайте проекты Snack на эмуляторах Android или симуляторах iOS.
- Используйте локальные файлы для установки и запуска приложений. Orbit поддерживает любые приложения с цифровой подписью в формате .apk для Android , совместимые с симулятором iOS приложения в формате .app или приложения, подписанные по умолчанию.
- Список закрепленных проектов можно посмотреть на панели управления EAS.   

Вы можете скачать Orbit с помощью Homebrew для macOS или напрямую из репозитория GitHub.  
`brew install expo-orbit`

### Инструменты Expo для VS Code
**Expo Tools** — это расширение для VS Code, улучшающее процесс разработки при работе с файлами конфигурации приложения. Оно предоставляет такие функции, как автозаполнение и IntelliSense для файлов конфигурации приложения, EAS, магазина приложений и модулей Expo.  
Вы также можете использовать его для отладки вашего приложения с помощью встроенного отладчика VS Code, чтобы устанавливать точки останова, проверять переменные, выполнять код через консоль отладки и многое другое.
### Тестирование прототипов с помощью Snack и Expo Go.
#### Перекус
**Snack** — это среда разработки, работающая в браузере и похожая на Expo Go. Это отличный способ делиться фрагментами кода и экспериментировать с React Native, не загружая никаких инструментов на свой компьютер.
#### Expo Go
**Expo Go** — это бесплатная, открытая платформа для студентов и учащихся, позволяющая им попробовать React Native. Она работает с Android и iOS. 

### CLI
**CLI** — это автономный инструмент, который загружает исполняемый файл Expo Go для платформы и конкретной версии SDK или выводит его URL-адрес для загрузки. Укажите версию SDK `expo-go` , чтобы зафиксировать конкретный релиз, или опустите её для последнего релиза, а также укажите платформу для загрузки нужного исполняемого файла.
